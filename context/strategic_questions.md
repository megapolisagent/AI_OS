# strategic_questions.md
## Strategic Questions — вопросы без принятого решения

### Назначение

Хранит стратегические вопросы и идеи, по которым сознательно ещё не принято решение.

Файл не является:
- TODO
- roadmap
- журналом идей
- архивом

Попадание сюда означает только одно: «Эта тема признана достаточно важной,
чтобы не потерять её, но решение будет принято отдельно.»

---

### Правила

- Не содержит решений.
- Не содержит рекомендаций.
- Не содержит статусов «реализовано» или «отменено».
- Каждый пункт заканчивается открытым вопросом.
- Удаляется только после явного решения Марии.
