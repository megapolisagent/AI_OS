## 4. Weekly Experiment — выбранная гипотеза

Собрать ОДНУ кинематографичную мини-презентацию для одного реального объекта
из property-analyst, вручную, как HTML-артефакт (скролл-сцены на реальных
фото + текст) — **без Higgsfield MCP и без переключения на Fable 5**. Working
Loop First: проверяем саму гипотезу подачи (меняет ли это реакцию клиента),
не тащим за собой ещё не настроенную интеграцию.

### Почему не Higgsfield/Fable 5 сразу

- Ни то, ни другое реально не подключено — обсуждали, не сделали.
- property-analyst сейчас — PDF-генератор на данных Циан/2GIS, фото объектов
  в проекте нет вообще (папка `reports/` пуста).
- Артефакт на реальных фото — самый дешёвый достаточный тест (Simple Before
  Scalable), MCP имеет смысл добавлять только если ручной тест подтвердится.

### БЛОКЕР — единственное, что нужно от Марии

property-analyst работает с клиентами агентства — репутационный риск при
ошибке (см. PROJECT_DNA.md → «Репутационные запреты»). Фабриковать тестовый
объект с придуманными фото недопустимо даже как тест. Нужен **реальный** вход:

1. Адрес/название объекта (текущий, реальный)
2. Несколько фотографий (интерьер/экстерьер/локация — сколько есть)
3. Пара строк контекста — что в объекте примечательного (материалы, история
   дома, вид)
